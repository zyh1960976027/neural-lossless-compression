# 训练与评估

所有操作通过根目录 `run.py` 或 `python -m neural_compression` 执行。当前固定 BPE 4096、两层 Mamba-3、2048-token 独立分块，默认有效批大小 72、微批大小 72、数据加载进程数 0。模型及训练配置集中在 `neural_compression/config.py`，训练循环位于 `neural_compression/training.py`，评估位于 `neural_compression/evaluation.py`。

```bash
python run.py train --source datasets/raw/enwik9 --run-dir experiments/train/bpe4096_new
python run.py train --train-file 数据路径 --validation-file 验证数据路径 --run-dir 实验目录
```

第一种方式只取前 100,000,000 字节训练、随后 10,000,000 字节验证，省略数据参数时也使用本机 enwik9。第二种方式读取两个文件的完整内容，不要求 1 GB；必须同时提供训练和验证文件，不能与 `--source` 混用。分词器仅从训练集学习，不准备测试集或其他表示方案。程序逐字节核对分词还原结果后写入缓存，词表不足 4096 时明确报错，不缩小词表。

```bash
python run.py train --train-file 数据路径 --validation-file 验证数据路径 \
  --tokenizer checkpoints/bpe4096/tokenizer.model --run-dir 实验目录 \
  --batch-size 72 --micro-batch-size 24 --workers 0 --device cuda:0
```

`--tokenizer` 复用符合可逆配置的 BPE 4096 模型，微批大小必须整除有效批大小。梯度按有效预测位置累积，保留尾块掩码、第一轮学习率预热、验证平台降学习率及早停算法。默认累计 5 轮未达到 0.001 BPB 改善时将学习率减半，累计 15 轮时早停；每轮验证保存最佳权重，定时和退出时保存最新训练状态。`--max-epochs N` 设置累计轮数上限，适合短训练和排查，达到上限不标记为收敛。

实验目录中，`config.json` 固定输入摘要及配置，`prepared.json` 固定分词器和缓存校验值，`data/` 保存两份 token 缓存及 enwik9 切片，`tokenizer.model` 为本次分词器。`preflight.json` 记录一次真实训练更新与验证预检；`checkpoints/latest.pt` 保存优化器、随机状态、轮内位置和早停状态，`checkpoints/best.pt` 保存最佳权重。`history.json`、`summary.json`、`bpb_vs_steps.png` 和 `provenance.json` 保存训练记录及代码版本。`inference.pt` 从最佳检查点导出，未完成首轮时可从最新状态导出，并记录来源摘要。

再次执行同一命令即可续训。输入内容、分词器、缓存、模型或训练配置变化时拒绝复用；修改累计轮数上限可以继续训练。实验锁阻止同一目录并发训练。新推理包和配套分词器保存在本次目录，不替换 `checkpoints/bpe4096/` 的选定基线。

```bash
python run.py evaluate --input 数据路径 --checkpoint 实验目录/inference.pt \
  --tokenizer 实验目录/tokenizer.model --batch-size 72 --device cuda:0
```

评估使用独立的 2048-token 块，尾块只累计真实预测位置，每块首 token 计入 12 bit 均匀成本，总负对数概率除以原始字节数得到模型概率 BPB。评估临时缓存用完即删除，输出可通过 `--results 路径` 留存。模型概率 BPB 与包含分词器、整数频率及容器开销的完整文件 BPB 含义不同；后者请运行 `encode`。

旧的根目录 `train.py`、`evaluate.py` 和多方案搜索脚本仅在[历史版本](历史索引.md)中使用。
