# 无损编解码

当前主线使用 `run.py encode`、`decode` 和 `roundtrip`，配套权重、环境和最短命令见 [README](../../README.md)。模型预测 BPE 子词的概率，GPU 将其量化为总频率为 2²⁴ 的正整数区间，CPU 上的 Constriction 范围编码器据此压缩。每块最多 2048 个 token，首 token 使用均匀频率，各块循环状态独立；默认每批同时处理 1024 块。

```bash
python run.py encode --input datasets/raw/enwik9 --output experiments/test/enwik9.m3rc
python run.py decode --input experiments/test/enwik9.m3rc --output experiments/test/enwik9.decoded
python run.py roundtrip --input 数据路径 --compressed 压缩路径 --decoded 恢复路径
```

码流嵌入分词器，记录权重、环境、批大小和量化配置。编码端通过双缓冲预取下载实际符号的整数区间；解码端下载完整累计表逐步恢复 token，再还原字节。CUDA Graph 按批形状缓存并重放，完整批与尾批分别维护上下文。现有 GPU 计算顺序与优化保留。

解码先检查格式和运行配置，再核对每帧校验、总 token 数、原文长度及 SHA256；`roundtrip` 额外逐字节比较原文。输入和输出必须不同，已有文件拒绝覆盖，失败时删除本次尚未完成的输出。JSON 指标中 `actual_bpb` 包含分词器及完整容器，`payload_bpb` 只统计范围编码负载。

主线固定 GPU 整数量化，不再提供概率模式选择。旧字节格式与 FP32/FP16 子词格式请按[历史索引](历史索引.md)检出对应版本解码或重新生成；历史码流和恢复副本已按清单清除，报告、权重、分词器及输入继续保留。
