# 项目目录与文件职责

[README](../README.md) 是唯一项目使用入口。根目录只保留 `run.py` 一个 Python 操作入口，统一训练、评估、压缩、解压与往返校验；`python -m neural_compression` 调用同一套命令行实现。

## 当前源码

| 模块 | 职责 |
| --- | --- |
| `neural_compression/config.py` | 固定模型、训练配置及默认资产路径 |
| `neural_compression/model.py` | 两层 Mamba-3、参数核对、严格检查点加载及混合精度上下文 |
| `neural_compression/data.py` | 可逆 BPE、语料划分、训练专用数据准备、缓存核验及独立 token 块 |
| `neural_compression/training.py` | 训练预检、梯度累积、验证平台控制、检查点恢复与推理包导出 |
| `neural_compression/evaluation.py` | 尾块掩码、有效位置损失及包含首 token 成本的模型概率 BPB |
| `neural_compression/inference.py` | 循环状态、对齐缓冲、双缓冲预取和 CUDA Graph |
| `neural_compression/codec.py` | 当前 GPU 整数容器、分块编解码、校验和实际文件 BPB |
| `neural_compression/entropy.py` | GPU 整数累计表与 CPU 整数范围编码接口 |
| `neural_compression/io.py` | 防覆盖、原子写入、摘要、随机状态、曲线及版本信息 |
| `neural_compression/cli.py`、`__main__.py` | 参数解析、路径检查和命令调度 |
| `native/integer_range/` | Constriction 0.4.2 的 Rust 整数接口及锁定依赖 |
| `tests/` | 当前主线的数据、训练、熵编码、容器和真实 GPU 检查 |

训练核心放在 `training.py`，数据和评估分别集中到 `data.py`、`evaluation.py`；根目录入口只负责把用户命令交给核心模块。旧字节实现、多方案训练、FP32/FP16 子词格式和词表规模分析已退出主线，源码保存在历史标签和方案分支，不在当前目录保留副本。

## 保留工具

`tools/` 仅保留以下三类工具。验证记录见[主线整理报告](实验报告/主线整理/实验报告.md)。

| 工具 | 用途与调用 | 验证状态 |
| --- | --- | --- |
| `tools/build_integer_range.py` | `python tools/build_integer_range.py`，按 Cargo.lock 构建本机共享库 | 本机锁定依赖构建与整数接口测试通过 |
| `tools/benchmark_baseline.py` | `python tools/benchmark_baseline.py --input 样本 --output-dir 新目录`，当前基线三次独立进程测速；可用 `--reference` 对照 | 真实 GPU 编解码和报告生成通过 |
| `tools/install_conda_hooks.sh` | `bash tools/install_conda_hooks.sh`，安装本项目已有 Conda 环境的激活/退出配置 | Bash 语法与临时环境安装检查通过 |
| `tools/activate.sh` | `source tools/activate.sh`，激活 `mamba3` 的可选快捷方式 | Bash 语法与受控激活检查通过 |
| `tools/conda/activate.sh`、`deactivate.sh` | 由 Conda 自动调用，设置及恢复本机环境变量 | 临时环境激活/退出恢复检查通过 |

本机辅助工具保留已存在的环境名及 CUDA 路径，其他机器按[运行环境](使用指南/运行环境.md)调整。编译产物 `_integer_range.so` 不纳入 Git，构建应在编解码进程结束后执行。

## 数据、文档与迁移

`datasets/` 保存原始数据，`checkpoints/` 保存默认权重的本地位置，`experiments/train/` 保存新训练目录，`experiments/test/` 保存当前测试与测速，`experiments/tokenizers/` 保存既有子词实验。已有原始数据、切片、token 缓存、权重、分词器、配置、日志和报告原位保留。已确认的旧码流和恢复副本按照清单清除；用途不明的文件保留，不再把旧实验目录视为可直接续跑的完整目录。

中文文档按用途归入 `docs/使用指南/`、`docs/实验方案/`、`docs/实验报告/`，新实验汇总命名为 `实验报告.md`；`docs/实验数据/` 只存纳入 Git 的精简结果和清理清单，图片放在 `docs/图片/`。完整历史文档与材料导航见[历史索引](使用指南/历史索引.md)。

| 整理前路径 | 当前归属 |
| --- | --- |
| 根目录 `train.py`、`evaluate.py`、`codec.py` | 移除，统一为 `run.py` 的五个子命令 |
| `tokenization.py`、子词准备代码 | `data.py` |
| `token_training.py`、仍需使用的训练公共工具 | `training.py`、`evaluation.py`、`io.py` |
| `codec_graph.py`、推理基类及对齐工具 | `inference.py` |
| `token_codec.py` 的 GPU 整数路径 | `codec.py` |
| `integer_range.py` | `entropy.py` |
| `scripts/build_integer_range.py`、环境脚本 | `tools/` |
| 旧字节格式、多方案、词表规模与早期分析脚本 | `archive/pre-cleanup-20261021`，原路径可检出 |

项目沿用通用名称 `neural-lossless-compression` 和包名 `neural_compression`。本地工作区、Conda 环境和历史资产继续使用已有路径，以保持记录中的路径有效；未来模型替换集中修改核心配置与实现。五个长期分支及上传 GitHub 的后续安排见[版本管理与协作](使用指南/版本管理与协作.md)。
