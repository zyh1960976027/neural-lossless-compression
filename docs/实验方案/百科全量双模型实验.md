# 完整 enwik9 双模型编解码实验

> 历史记录：本文保留当时的实现、命令和测量口径。复现须检出对应历史版本，源码及保留材料见[历史索引](../使用指南/历史索引.md)。旧码流和恢复副本按清单清除，旧实验目录不能直接续跑。

本实验在相同的 1,000,000,000-byte enwik9 数据上分别测试两层 3.46M 模型和四层 6.73M 模型。前向评估、编码、解码各在独立进程中执行。前向评估使用 2048-byte 窗口、batch size 128，先预热两个 batch，再统计正式推理时间。编解码使用 v5 CUDA Graph、2048-byte 独立块和 batch size 1024；每个进程先加载模型并准备实际需要的图，再统计完整编解码时间。

编解码时，每块第一个字节使用均匀分布，其余字节由模型依次预测。模型输出转换为 256 个字节取值的概率，Range Coding（区间编码）据此选择实际字节对应的概率区间。解码使用相同模型和此前恢复的字节重现概率，再逐字节恢复原文。程序最后比较原文与恢复文件，并核对 SHA256。

## 运行顺序

在项目根目录执行。完整实验至少预留 5 GB 空间，运行期间避免其他 GPU 任务。当前环境可通过 `source scripts/activate.sh` 激活；如使用其他已配置环境，确保安装项目和编解码依赖。

先运行 CPU 回归：

```bash
source scripts/activate.sh
python -m unittest discover -s tests -v
```

然后执行 10 MB 预检。它对两个模型分别完成前向评估、编码、解码和逐字节校验，保留 10 MB 输入切片：

```bash
python scripts/benchmark_enwik9_full.py preflight
```

确认终端输出中的 `both_models_complete`、`all_roundtrips_verified`、`all_metrics_finite` 均为 `true`，再运行完整 1 GB 实验：

```bash
python scripts/benchmark_enwik9_full.py full
```

程序在 `experiments/test/<时间戳>_enwik9_preflight/` 或 `experiments/test/<时间戳>_enwik9_full/` 创建独立目录，不覆盖已有结果。若进程中断，找到该目录后使用同一模式恢复：

```bash
python scripts/benchmark_enwik9_full.py full \
  --resume-dir 'experiments/test/<时间戳>_enwik9_full'
```

恢复前会核对实验清单、源文件、权重、代码和已完成的编解码文件。已完成的前向评估不会重跑；中断后留下的不完整编解码文件会移入 `codec/incomplete/` 保存，再重试该阶段。已完成文件若校验不一致，程序会停止并保留现场供检查。

## 结果与指标

顶层 `summary.csv` 每个模型一行，`results.json` 保存完整指标，`实验报告.md` 提供中文汇总，`run_manifest.json` 保存数据、权重、代码指纹和运行配置。各模型目录保存 `inference.json`、`complexity.json`、阶段日志，以及 `codec/` 下的压缩文件、恢复文件和逐字节校验记录。压缩结果和恢复结果不会自动删除。

主 BPB 按完整压缩文件字节数乘以 8、再除以原始字节数计算。另列编解码理论 BPB 和前向评估 BPB。前者按编解码时的独立块和均匀首字节口径计算；后者按整块前向评估的窗口口径计算，两者不要求相等。

推理速度按前向评估有效预测字节数除以预热后的模型前向时间计算。编码和解码速度按全部原始字节数除以端到端时间计算，包含读写、状态初始化、模型推理、概率处理、区间编码或解码及校验，不含模型加载和预热。单位为十进制 KB/s。

峰值显存主结果是前向、编码、解码三个进程的 PyTorch 张量分配峰值中的最大值；前向预热与正式评估、编解码模型加载与预热也分别保留记录。缓存预留峰值单列。结果不包含 CUDA 上下文、第三方库直接分配量或其他进程用量，单位为十进制 GB。

参数量从实际加载的权重统计，并与模型结构的解析结果比较。MACs 指一次乘加运算，按单个预测字节统计模型线性投影、输出头，以及每层 Mamba 循环状态的衰减、两次注入和一次读出。归一化、激活、旋转、指数运算、概率量化和区间编码不计入。结果同时给出每个预测字节、完整 2048-byte 块和整份 enwik9 的 MACs；块首均匀编码字节不产生模型 MACs。这是明确口径的解析计数，不是 GPU 实际执行指令数。

完整文件分为 488,282 块，其中模型预测 999,511,718 个字节、均匀编码 488,282 个块首字节。两个模型分别只进行一次完整正式运行，因此速度应保留运行环境信息，不能视作多次实验的统计均值。
