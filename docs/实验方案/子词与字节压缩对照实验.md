# SentencePiece 与字节表示的无损压缩对照

> 历史记录：本文保留当时的实现、命令和测量口径。复现须检出对应历史版本，源码及保留材料见[历史索引](../使用指南/历史索引.md)。旧码流和恢复副本按清单清除，旧实验目录不能直接续跑。

本实验比较字节、SentencePiece BPE、SentencePiece Unigram 三套压缩系统。
字节组复用两层无 MTP 的 `checkpoints/best-3M.pt`；两组子词模型采用相同骨干和 4096 词表，
总参数量分别为 3,455,436 和 6,158,796。SentencePiece 固定为 0.2.1。

enwik9 按原始字节划分为前 100 MB 训练、随后 10 MB 验证、后 890 MB 独立测试。
完整 1 GB 另作历史可比性补充。分词器仅从训练部分学习；测试内容只用于还原检查和最终评测。

## 执行

在具有 GPU 访问权限的环境中激活项目环境，选择一个独立实验目录：

```bash
source scripts/activate.sh
python -u scripts/benchmark_sentencepiece.py all \
  --run-dir experiments/tokenizers/enwik9_sp4096_20261019
```

正式 `all` 运行要求受版本管理的工作区干净。可用同一命令恢复；已验证且配置、代码和文件
指纹一致的阶段会复用结果。阶段也可单独运行，依次为 `prepare`、`preflight`、`tune`、
`train`、`evaluate`、`report`。`train --algorithm bpe` 或 `unigram` 可单独恢复一个模型。
正式训练必须先通过完整分词可逆性检查和 GPU 编解码预检。

`prepare` 保存数据切片、词表、线程测速、token 缓存及其指纹。训练和编解码均使用连续
token 流上的独立 2048-token 块，每块首 token 均匀编码，只训练块内其余 2047 个条件预测。
每轮打乱块顺序，尾块通过掩码排除填充及无目标位置。验证 BPB 包含每个块首 token 的成本。

分词保留换行，超长行在 UTF-8 边界拆为不超过 64 KiB 的片段。关闭规范化、空白删除、
额外前缀和随机分词；特殊“▁”及无效字节直接使用字节回退符号。解码将词条还原为字节，
不会因跨块的不完整 Unicode 字符丢失信息。两种算法在完整 1 GB 上逐段比较原始及恢复字节，
同时记录 SHA256；1、2、4、8、12、24 线程候选在验证集上各测三次，核对 token 序列一致。

`preflight` 先测试 256/4096 类均匀、随机、尖峰及零概率分布的整数频率量化与区间编码，
再用非零输出头的预检模型对 10 MB 验证集进行三次独立进程编解码。统计概率生成、传输、
量化与区间编解码及完整流程的耗时。量化与区间编码在库内融合，报告二者的合计时间。
预检权重用于正确性和速度检查，其压缩率不代表正式模型效果。

`tune` 在独立进程中探测完整训练步的吞吐及峰值显存，保留约 1 GiB 余量，选择共同稳定的
训练 batch，并比较数据加载线程。正式编解码 batch 固定为 1024，训练 batch 单独记录。

## 训练控制与恢复

Adam、BF16，随机种子 2026；首轮线性预热至 0.0006。每轮完整验证，累计 5 轮改善不足
0.001 BPB 时学习率减半，最低为 0.000006；累计 15 轮无实质改善时早停。
小幅改善可累积，任何验证新低都保存 `training/best.pt`。
12 小时是进度检查点，不是训练上限。每轮及每 15 分钟保存 `training/latest.pt`，
包括优化器、随机状态、轮内位置和早停计数。SIGINT/SIGTERM 在训练步完成后保存进度。
`training/summary.json`、`history.json` 和 `bpb_vs_steps.png` 记录实际训练情况；
训练尚未达到早停判据时，最终评测入口会拒绝执行。

## 压缩格式和结果口径

字节路径保留 v5 格式；子词容器采用独立 `M3SP` v1 标识，内嵌分词器，并保存原始长度、
每组 token 数、总 token 数、批处理配置、权重和运行环境指纹。每组包含共享区间编码流，
帧 CRC 与尾部原文 SHA256 用于检测损坏；失败时删除本次不完整恢复文件。
解码只依赖压缩文件、匹配的神经权重和兼容环境。

主表 `summary.csv` 和 `results.json` 报告 890 MB 独立测试与完整 1 GB 补充结果。
实际 BPB 包含完整压缩文件及分词器；含权重 BPB 再加入仅包含推理权重和配置的推理包，
不计优化器等训练状态。编解码速度按原始字节数计算，单位 KB/s（1000 bytes/s）。
分词、文件读写、模型推理、概率处理、区间编码和内部校验计入时间；模型载入、图准备和
预热单列。正式编码重新读取原文并分词，不用缓存替代分词计时。

所有恢复结果逐字节比较并核对 SHA256。报告尚未完成时明确显示缺失阶段，不填估计结果。
历史完整 enwik9 字节记录为 BPB 1.337071088、编码 361.73 KB/s、解码 371.81 KB/s。

## 检查

```bash
python -m unittest discover -s tests -p 'test_token*.py' -v
MAMBA_CODEC_GPU_TEST=1 python -m unittest discover -s tests -p test_token_gpu.py -v
```

CPU 检查覆盖任意字节、分词线程一致性、独立块损失、早停恢复、编码边界和损坏拒绝。
GPU 检查覆盖 4096 类概率、最高 token 编号、完整 2047 次递推、状态清零和图缓存切换。
