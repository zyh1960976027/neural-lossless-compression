# 主线结构整理与验证报告

本次将主线固定为 BPE 4096（最大编号 4095）、两层 Mamba-3（6,158,796 参数）、GPU 整数量化与 Constriction 范围编码。选定权重、分词器、模型配置及既有 GPU 计算、双缓冲预取和 CUDA Graph 行为保持一致。整理于 2026-10-21 开始，2026-10-22 完成核验。

## 代码与使用流程

根目录仅保留 `run.py` 一个 Python 操作入口，提供 `train`、`evaluate`、`encode`、`decode`、`roundtrip`；`python -m neural_compression` 调用同一实现。配置、模型、数据、训练、评估、推理、编解码、整数范围编码和公共 I/O 分别集中到核心模块，命令行只解析参数并调度。主线撤去旧字节格式、FP32/FP16 子词格式、多方案对照、词表规模实验和早期性能分析代码，开发辅助工具仅保留整数扩展构建、环境配置与当前基线测速。职责与调用方式见[目录说明](../../目录说明.md)。

训练只准备训练集与验证集。默认读取 enwik9 前 100,000,000 字节训练、随后 10,000,000 字节验证，也支持读取两个自定义文件的完整内容；BPE 仅从训练部分学习，或复用已有 BPE 4096 分词器。数据、分词器和配置一致时自动续训，变更时拒绝复用。有效批大小默认 72、加载进程数 0，保留独立 2048-token 分块、梯度累积、平台降学习率及早停。最佳、最新检查点和独立推理包保存在本次实验目录，不替换默认基线。

## 功能、训练与工具验证

普通检查共 20 项，17 项通过、3 项显式 GPU 检查跳过；开启真实 GPU 后 20 项全部通过。检查覆盖空输入、任意字节、完整块、尾块、尾批、损坏检测、防覆盖、重复编码、循环状态重置，以及串行与预取整数区间一致性。10 MB 对照另外验证了独立进程解码与完整字节恢复。

真实默认模型完成了以下训练检查：复用选定分词器，在 4,099 字节训练集、2,051 字节验证集上完成首轮，再从最新检查点恢复到第二轮；使用 65,536 字节训练集与 16,384 字节验证集，自动学习完整 BPE 4096 分词器并完成短训练；导出的独立推理包通过加载、概率评估及编解码逐字节往返。测试同时验证输入或缓存变更拒绝、词表不足报错、掩码与每块首 token 均匀成本，以及受控模型的保存恢复和曲线生成。短训练验证流程正确，不表示模型已收敛。

默认 enwik9 准备流程实际生成前 100 MB 和随后 10 MB 两份切片、两份 token 缓存，摘要与保留的原切片一致；重复执行准备结果一致，未生成测试切片或其他方案。该检查复用已有 BPE 分词器，没有为本次整理重新进行全量训练。相关配置、日志、权重及结果保存在 `experiments/train/cleanup-verification-20261021/`。

整数扩展构建、接口测试通过；环境脚本通过 Bash 语法、临时环境安装、激活和变量恢复检查；当前测速工具通过真实 GPU 单轮检查及最终三轮对照。新旧三轮原始记录分别位于 `experiments/test/cleanup-baseline-before-20261021/`、`experiments/test/cleanup-baseline-after-20261021/`，精简验收数据随 Git 保存。
